# 提示词

把本地 Markdown 提示词目录搬进 DeepSeek 的主面板。左侧目录来自本地文件夹，右侧是提示词列表；打开提示词后在同一面板中可在「原文本 / 富文本 / 预览」三种模式间切换；左侧目录从 Markdown 标题生成，支持折叠、跳转和整栏打开/收起；富文本工具栏「引用」可搜索本地提示词/文件并插入链接；也可「插入图片」，复制到根目录固定的 `assets/` 文件夹后自动插入并通过本地资源接口显示；富文本编辑内容自动序列化为 Markdown；停止输入约 1.2 秒后防抖写回原文件，手动保存仍保留。

## 使用

1. 在左侧边栏点击 **提示词**。
2. 默认目录：`~/Documents/DSH Prompts`（首次自动创建，可用 `LOCAL_DOCS_ROOT` 或 `local.config.json` 覆盖）。列表行和编辑页的文件区都有「复制完整路径」按钮。
3. 你在本地新增文件夹后，面板会自动读取，也可以点目录标题旁的刷新按钮。
4. 新建提示词会在当前目录创建 `.md` 文件；改标题会重命名文件，改目录会移动文件。
5. 删除会移动到 `.trash/`，可恢复或彻底删除。

## 在对话中 @ 提示词

在任意对话输入 `@`，候选菜单会有一个「本地提示词」分组；继续输入名称即可边打边搜。选中后插入的是该文件的绝对路径 mention，模型可以用 `read` 读取。

## 说明

安装或更新插件后需要重启 DeepSeek Harness，Host 端的本地 API 才会加载最新代码。

- 目录即分类，不在应用内新建分类文件夹。
- 支持 `.md`、`.markdown`、`.txt` 和无扩展名文本文件。
- 摘要从正文自动生成；标题就是文件名。
- 本地服务监听 `127.0.0.1:45127`，只允许本机来源访问。
- 需要 DSH 的 Host 与 Web 客户端同时加载本插件。
